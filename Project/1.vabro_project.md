# Project Explanation - VABRO

## About Project

I am currently working as a Front End Developer at Edusys Services Pvt. Ltd. on a SaaS-based Agile Project Management and Collaboration platform named VABRO.

The platform helps organizations manage projects, teams, sprint planning, task tracking, reporting, and analytics, from a single workspace.

My primary responsibility is frontend development using React.js, TypeScript, Redux Toolkit, HTML, CSS, and Bootstrap. I work on developing new features, integrating REST APIs, managing application state,Implementing role-based UI access, optimizing performance, Fixing bugs and building responsive user interfaces.

### My responsibilities included:

- Developing responsive UI screens using React.js and Bootstrap
- Creating reusable components for forms, tables, modals, and dashboards
- Integrating REST APIs with frontend applications
- Managing application state using Redux Toolkit
- Implementing authentication and authorization-based UI rendering
- Handling form validations and error handling
- Developing interactive charts using Chart.js and ECharts
- Optimizing performance using React hooks and memoization techniques
- Fixing bugs and maintaining existing modules
- Participating in sprint planning, code reviews, and daily standups

Some of the major modules I have worked on include:

- Project Dashboard with widgets and prject overveiw
- Reports for data visualization using Chart.js and Recharts.
- Comments for communicate with other workspace member within same workspace.
